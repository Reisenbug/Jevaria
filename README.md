# Jevaria

Jev 驱动的 Terraria Boss 战实验模组。Jev 每次选择一条躲避方向和幅度；模组读取战况、执行按键并用弹速与 Boss 速度计算提前量。

## 运行

1. 使用 tModLoader 2026.07 构建并启用 `Jevaria`。
2. 在客户端模组配置中填入 TypeSafe API key，或在启动 tModLoader 的进程环境中设置 `TYPESAFE_API_KEY`。环境变量优先；模组配置保存在本机的 tModLoader `ModConfigs` 目录，不写入仓库。
3. 进入单人世界，装备直线弹道的远程武器。任意 Boss 出现后自动开始；若曾输入 `/jevaria off`，用 `/jevaria on` 重新待命。
4. 按 `P` 开关躲避移动；可在 tModLoader 键位设置中修改。关闭躲避后仍自动瞄准、攻击。输入 `/jevaria off` 停止全部自动操作；`/jevaria hud` 开关游戏内决策显示。

玩家按下移动、跳跃、钩爪、坐骑或使用物品按键时，手动输入优先；Jevaria 不会清除原版按键状态。松开手动输入后自动操作恢复。
Boss 出现时自动选中快捷栏 0–9 格里最靠前的武器；手动切换物品后不再抢回。战斗结束且仍持有自动选中的武器时，恢复战前物品。

双子魔眼在场时使用 `Instruction`，其他 Boss 使用 `GeneralInstruction`。两者都可在 tModLoader 的 `JevariaConfig` 客户端配置中修改。第一轮目标为双子魔眼，移动装备为翅膀、二段跳和钩爪；装备 Slimy Saddle 时增加纯竖直 Large 动作。武器为飞镖手枪，飞镖种类由当前弹药决定。

## 当前实现

- 单人模式读取场上 Boss、主要 Boss 配件、来袭弹幕、玩家生命与四侧实体方块/世界边界距离。双子魔眼在场且魔焰眼存活时优先攻击魔焰眼。
- 将八方向加原地、幅度两个判断放在同一次 Jev 请求中；收到回答后切换动作，直到下一份回答生效。请求超时为 1.5 秒，旧动作最多保留 1.5 秒。
- 攻击和躲避分别运行；等待 Jev 首次回答或请求失败时，瞄准与射击仍可继续。
- 水平移动、跳跃/飞行输入、持续下穿平台和钩爪由动作接口执行。Medium 只在向上时尝试额外跳跃。装备 Slimy Saddle 后，纯上 Large 在起跳或钩爪拉完起跳时上坐骑并按住 W，上升结束后下坐骑；纯下 Large 上坐骑并按住 S，动作结束后下坐骑。斜向和横向 Large 仍只尝试钩爪；当前不请求冲刺。
- Boss 存活时，生命低于最大生命的 50% 或浸在岩浆中会调用原版 `QuickHeal`；药水冷却由游戏处理。
- 对使用匀速直线弹幕的武器，用目标速度与弹药、弹幕额外更新次数修正后的发射速度求截获点；发射速度不叠加玩家速度。飞镖手枪的发射点偏移也计入计算。
- 每次 Jev 决策在聊天栏显示方向、幅度与延迟。左上角只显示状态和 dodge 开关；预测瞄准点仍标在目标附近。tModLoader 日志保留战况、概率、实际动作、降级原因与喝药记录。

## 验证范围

目前通过 C# 编译。游戏内动作效果、真实 API 延迟、实战命中率和 Boss 击杀尚需实际加载与战斗验证。瞄准模型暂按匀速直线弹幕处理；有重力、追踪或特殊发射行为的武器需要单独适配。Boss 配件通过 `NPC.realLife` 和常见部件类型识别，其他关联机制需逐个 Boss 验证。

架构与实施顺序见 [DESIGN.md](DESIGN.md)。
