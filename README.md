# Jevaria

Jev 驱动的 Terraria Boss 战实验模组。Jev 每次选择水平/垂直躲避方向、各轴幅度与是否冲刺；模组读取战况、执行按键并用弹速与 Boss 速度计算提前量。

## 运行

1. 使用 tModLoader 2026.07 构建并启用 `Jevaria`。
2. 在客户端模组配置中填入 TypeSafe API key，或在启动 tModLoader 的进程环境中设置 `TYPESAFE_API_KEY`。环境变量优先；模组配置保存在本机的 tModLoader `ModConfigs` 目录，不写入仓库。
3. 进入单人世界，装备直线弹道的远程武器。双子魔眼出现后自动开始；若曾输入 `/jevaria off`，用 `/jevaria on` 重新待命。
4. 按 `P` 开关躲避移动；可在 tModLoader 键位设置中修改。关闭躲避后仍自动瞄准、攻击。输入 `/jevaria off` 停止全部自动操作；`/jevaria hud` 开关游戏内决策显示。

玩家按下移动、跳跃、钩爪、坐骑或使用物品按键时，手动输入优先；Jevaria 不会清除原版按键状态。松开手动输入后自动操作恢复。

Jev 的初始 instruction 可在 tModLoader 的 `JevariaConfig` 客户端配置中修改。它是待实战调整的草稿。第一轮目标为双子魔眼，移动装备为翅膀、二段跳和钩爪，暂不使用坐骑；武器为飞镖手枪，飞镖种类由当前弹药决定。

## 当前实现

- 单人模式读取双子魔眼、由 `realLife` 关联的配件、附近敌方弹幕、玩家能力与四侧实体方块/世界边界距离。魔焰眼存活时优先攻击魔焰眼。
- 将五个独立判断放在同一次 Jev 请求中；收到回答后切换动作，直到下一份回答生效。请求超时为 1.5 秒，旧动作最多保留 1.5 秒。
- 攻击和躲避分别运行；等待 Jev 首次回答或请求失败时，瞄准与射击仍可继续。
- 水平移动、跳跃/飞行输入、平台下落、钩爪和装备提供的冲刺由动作接口执行。首测不请求坐骑；无法执行的动作显示降级原因。
- 对使用匀速直线弹幕的武器，用目标速度与弹药、弹幕额外更新次数修正后的发射速度求截获点；发射速度不叠加玩家速度。飞镖手枪的发射点偏移也计入计算。
- 每次 Jev 决策在聊天栏显示方向、幅度、冲刺与延迟。左上角只显示状态和 dodge 开关；预测瞄准点仍标在目标附近。tModLoader 日志保留战况、概率、实际动作与降级原因。

## 验证范围

目前通过 C# 编译。游戏内动作效果、真实 API 延迟、实战命中率和 Boss 击杀尚需实际加载与战斗验证。瞄准模型暂按匀速直线弹幕处理；有重力、追踪或特殊发射行为的武器需要单独适配。Boss 配件目前通过 `NPC.realLife` 关联，其他关联机制需逐个 Boss 验证。

架构与实施顺序见 [DESIGN.md](DESIGN.md)。
